Scheduling routines

A routine is a prompt an assistant runs on a schedule: once, or repeating every so many minutes, days or weeks. Pick the start, the repeat and an end if you want one, then use Run now to try it before the first scheduled run.

Each run starts a fresh conversation owned by the assistant.
