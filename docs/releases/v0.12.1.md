# v0.12.1 — A responsive Windows installer

A small fix for the Windows installer: it no longer freezes while it closes the running app.

## Fixed
- On Windows, the installer no longer freezes while it closes the running GleepGlorp AI. In v0.12.0 the wizard could stop responding during an upgrade, including on its last page.
- The installer now writes a setup log to your temporary folder (`%TEMP%`, a file named `Setup Log <date> #<number>.txt`), which helps if an install ever needs troubleshooting.

## Notes
- Upgrading from v0.12.0 closes the app cleanly within about ten seconds.
