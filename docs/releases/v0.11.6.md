# v0.11.6 — Links open in your browser, and easier-to-read text

Links in agent replies now open in your default browser instead of inside the app window. Text and controls have more contrast in both light and dark themes, and this release fixes several smaller problems.

## Changed
- Text and controls now have more contrast in both themes. Every text colour meets WCAG AA (4.5:1) and every control meets 3:1, with no exceptions. Faint text such as timestamps and sender labels is the most visibly darker in light mode and lighter in dark mode.
- File and model sizes now use decimal units everywhere, so a model's size in the agent editor matches the Model providers panel and ollama.com.

## Fixed
- Clicking a link in an agent's reply in the desktop app now opens it in your default browser. Before, the page loaded inside the app window, which has no Back button, and you had to restart the app.
- Signing in to an MCP server that strictly checks request headers no longer fails with a 406 error after sign-in.
- Saving an agent no longer risks removing its MCP servers if the MCP server list failed to load.
- When a Claude Plan provider needs you to sign in again, the message now points to Library › Model providers. Before, it pointed to "Administration", which no longer exists.
- The token expiry dates in the Claude Plan (Token) editor now update straight away when you change the time zone.
- Sending a request body that is valid JSON but not an object now gets a clear error instead of a server error.
- Two knowledge bases whose search tools would end up with the same name now log an error, instead of one silently replacing the other.
- Knowledge base indexing picks up waiting files in a consistent order.
- A slow knowledge-base save at shutdown can no longer be written twice at the same time.

## Notes
- Nothing to reconfigure, and no database changes.
