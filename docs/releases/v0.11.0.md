# v0.11.0 — Agent rules and notes

Minor release over [v0.10.5](https://github.com/msieurthenardier/the-one/releases/tag/v0.10.5). Each agent can now follow standing rules you write and keep short notes for itself.

## Added
- **Rules.** A new "Rules and notes" tab in the agent editor holds an ordered list of standing instructions for that agent. You can add, edit, switch on or off, reorder and delete rules, and each change saves at once. The agent cannot change its rules, and they outrank its notes.
- **Notes.** An agent can save short notes for itself and use them in later conversations. Notes are off by default; the "Let this agent keep notes" switch on the same tab turns them on. Each note shows where it came from, and you can edit or delete notes, or clear them all.
- **Flagged notes.** A note is marked "Check this" when content that did not come from you was anywhere in the conversation where it was written. Editing a note yourself clears the mark.
- **Rules and notes in the chat panel.** The agent panel in a chat shows the agent's rules and notes read-only, marks flagged notes with a warning triangle, and lists notes that the open chat does not use yet under "Pending · used from the next chat".
- **Prompt layers on screen.** Settings › Prompts now shows every fixed layer of the agent's prompt, in the order they are put together.

## Fixed
- Renaming an agent that has self-configuration revision history now works.
- A self-configuration change that takes effect on the next turn no longer drops the agent's base prompt.

## Notes
- Rules and notes reach every new conversation, in the app and in connector channels.
- **Upgrading:** the database is upgraded automatically on first start (two schema steps). Nothing to reconfigure; notes stay off until you turn them on per agent.
