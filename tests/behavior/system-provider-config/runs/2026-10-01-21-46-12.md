## Orchestrator Notes

- **Apparatus substitution.** The spec mandates chrome-devtools so that it can reload with the cache ignored. No chrome-devtools MCP is registered in this session, and goldfinch had stopped delivering input on this host. The Executor therefore drove a dedicated headless Chromium 147 over CDP (`127.0.0.1:9336`) with Playwright:
  - a persistent raw-CDP context;
  - real input events, with `select_option` only on the native Type select;
  - ignore-cache reloads via CDP `Page.reload {ignoreCache:true}`;
  - screenshots as primary evidence.
  
  This meets the spec's intent of a CDP-driven Chromium with ignore-cache reloads.
- **Light variant theme.** The Light pass ran on Auto, which resolves to light, rather than an explicitly set Light. This is a minor deviation; the rendering is identical.
- **Dark pass batched.** The Executor ran D0 and D2–D10 as one batch with per-checkpoint evidence. The Validator judged each checkpoint separately.
- **Concurrency incident.** The concurrent Executors shared a scratchpad, and generic script names collided. Another run executed a copy of this run's step-7 script; it timed out on `#pf-name` without acting. This run's own evidence is self-consistent, and the server state confirms the single rename.
- **Finding: the delete arm is asynchronous.** The provider Delete click first runs an agent-usage pre-fetch (`GET /api/providers/{id}/agents`) and only then arms; the arm appears at about 57–130 ms. Probes must poll for the "Confirm Delete?" label rather than read at a fixed delay.
- **Observation (accessibility, Flight 2 router).** After a provider save-create, the editor's route canonicalisation goes through `App.router.sync()`. That re-titles without announcing, so the visually hidden `#route-announcer` keeps "Settings — Providers — New" until the next navigation. Agent save-create uses `go(replace)` and does announce. This inconsistency is logged as a squawk candidate.
- **Spec wording is stale:**
  - the Intent's "System / Admin Re-skin";
  - the `admin.js` reference;
  - the chrome-devtools-only apparatus mandate, which could accept any CDP-driven Chromium.
