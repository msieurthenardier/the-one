## Deviations

- **`llm/base.py` NOT edited — the shared-constant reconciliation uses the "assert" branch, not "import".** The leg's Context and Files Affected anticipated `llm/base.py` importing the tool-name/prefix constants from `tools/connector_send.py`. Doing so would make `the_one/llm/` import from `the_one/tools/`, which nothing else in the codebase does (tools depend on llm-adjacent layers, not the reverse) — a layering inversion for two string literals. The leg's own Context text offered the alternative explicitly ("llm/base.py importing OR asserting it"), so `llm/base.py` is byte-identical to `main` (confirmed: `git diff main -- the_one/llm/base.py` is empty) and `tests/test_connector_send_tool.py::test_shared_constants_pin_llm_base_literals` pins agreement by inspecting `tag_post_step_visibility`'s source for both literals via `inspect.getsource`. Flight-end Reviewer should re-confirm this satisfies the debrief-landmine intent — the pin is source-textual rather than a live import-time equality assert, so it would not catch a change that keeps the literal's *value* but reformats the source in a way `inspect.getsource` still contains the substring (extremely unlikely, but worth a second look).
- **`tests/conftest.py` NOT edited — no shared teardown hook added.** The leg's Files Affected list flagged this as "if needed." It wasn't: each new test file that starts a `ConnectorManager` (`test_connector_send_tool.py`, `test_connector_history_tool.py`, `test_connectors_manager.py`, `test_connectors_inbound.py`) either calls `manager.drain()` directly at the end of the test or tracks every manager it creates in a module-level list drained by an autouse fixture's teardown — the "Stub in unit tests must not leak tasks" Edge Case is honored without a cross-file conftest primitive. `the_one.connectors.registry.clear_for_test()` and `StubPlugin.reset_for_test()` are the two per-test resets in play, both called from local autouse fixtures, mirroring the existing `the_one.sessions.clear_for_test()` / MCP-pool `_clear_for_test()` precedent without adding a new global convenience wrapper (nothing outside this leg's own tests needs one yet).
- **Pre-existing `tests/test_db_repositories.py::TestConnectorRepository` tests fixed for the new DD-2 validator (out of the leg's Files Affected list).** `test_create_and_get`, `test_secrets_round_trip`, and `test_empty_secrets_default` constructed `Connector(config=...)` with pre-reset-era keys (`"intent"`, `"x"`) that predate DD-2 and are now rejected by the new reserved-key validator. Fixed by switching both to a DD-2-compliant `config={"default_agent": "bot-1"}`; the tests' actual intent (config round-trips through the encryption-adjacent CRUD path unchanged) is preserved.

DD-1's manager owns "listener task lifecycle" but the pipeline lives in `inbound.py`, not inside each plugin — a plugin's internal gateway listener (e.g. a future Discord `on_message` handler) needs a way to hand inbound envelopes back to the pipeline without importing `the_one.connectors.inbound` itself (which would invert the dependency direction DD-1 implies: plugins are leaves, the manager wires them up). Threading the callback through `connect()`'s signature keeps that direction intact. Flight-end Reviewer / Flight 3 (Discord plugin) should treat this as the now-canonical `ConnectorPlugin.connect` signature.
- **No persisted "enabled" field on `Connector` — DD-9's form-field list and DD-7's "credential/enabled/type change restarts the listener" wording assume one exists; it doesn't.** Leg 1's DD-2 config validator (`db/models.py`) has a closed reserved-key set — `{"default_agent", "channel_map", "allowlist", "always_listen"}` — with no `enabled` key, and `Connector` carries no top-level boolean column either (confirmed against the current schema and leg-1's landed model). The Studio form has no "enabled" checkbox. **Flight-end Reviewer / a future leg should treat this as an open item** — if the operator needs to pause a connector without deleting it, that's a genuine follow-up (new column + migration), candidate for a squawk or Flight 3/4 scope, not silently expanded into this leg.
