## Bugs found & fixed during the HAT

| # | Bug | Root cause | Fix (commit) |
|---|-----|-----------|--------------|
| 1 | App "didn't launch" — silent exit | A stale **the-one Docker container** held 8484; `_select_port` correctly saw a the-one of our version and F6 focus-and-exited. **Not a code bug** — environment. | Operator removed the container. (Code follow-up tracked: the no-window-`serve` case — see Known Issues.) |
| 2 | Windowed app silent crash | `the-one-app.exe` (console=False) has `sys.stdout=None`; uvicorn's logging calls `sys.stdout.isatty()` → AttributeError. Pre-existing **F4 latent bug** (rendered-window HAT never run). | `ensure_stdio_streams()` redirects None stdio to a `data_dir/logs` file (`25e200a`) |
| 3 | Window geometry never restored | `run_desktop` called `webview.screens()` but the installed pywebview exposes `screens` as a `proxy_tools` **list**, not a function → `'list' not callable` → restore fell back to defaults. Mocks hid it. | robust screens resolution + capture logging (`76dd170`) |
| 4 | Window resized on tray-Show | `on_show` called `window.restore()` on a hidden (not minimized) window. | dropped `restore()` from `on_show` (`76dd170`) |
| 5 | Over-the-top install couldn't close the app | F6 close-to-tray turns the installer's WM_CLOSE into hide-to-tray; the background process kept files locked. | `CloseApplications=force` + `PrepareToInstall` taskkill backstop in the `.iss` (`41c51fe`) |
