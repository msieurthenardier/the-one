# v1.1.0 — Small windows

The app now works at every window size the desktop app allows, down to its 640×360 minimum and a window snapped to a third of the screen. Deleting an agent now deletes its chats too.

## Added
- **One pane at a time in a narrow window.** Below 768px wide, each page shows either its list or the item you opened, using the whole width.
  - Choosing Chats, Agents, Library or Settings shows its list (Settings shows its menu). Opening an item shows the item.
  - To get back to the list, click the page's icon on the left again. Back in the browser works too.
  - At 768px and wider, the list and the item sit side by side as before.
- **Side panels fill a narrow window.** Below 768px, a chat's agent panel and GleepGlorp's drawer open across the whole page, with the page behind them out of reach until you close them.
  - The agent panel gets a **✕ Close** button in a narrow window. Esc also closes either panel, and moving to another page closes it.
  - In a narrow window the agent panel starts closed each time.
- **Tabs and header buttons fit a narrow window.** Below 768px, a row of tabs (an agent's General, Rules and notes, Tools and so on, or the Built-in tools categories) becomes one button naming the current tab; it opens a list of all the tabs. An agent's **Chat** button moves into a **⋯ More actions** menu beside Cancel and Save.
- **A confirmation before deleting an agent.** Delete now opens a dialog that names the agent and how many chats it has. Delete stays disabled until you tick "I understand this will delete all of this agent's chat history".

## Changed
- **Deleting an agent deletes its chat history.** Before, an agent's chats stayed behind in Chats after the agent was deleted.
- **Short windows are more compact.** In a window under 480px tall, the chat header is smaller and the message box keeps the attach button, the text, the model and Send on one row, so more of the conversation shows. The left rail scrolls if its icons don't fit.
- **Nothing scrolls sideways.** Dialogs, the tool tiles and form margins shrink to fit narrow windows.

## Fixed
- **Keyboard focus is no longer lost** when a proposal card folds after an update, or when you remove a chip (a tag-like item in a field) with its button.
- **Esc inside a chart** no longer also closes the GleepGlorp drawer.
- **Two changes to the same agent at once** can no longer silently overwrite each other's saved credentials.
- **The GleepGlorp button** no longer covers the last item of a list in a narrow window.

## Notes
- **The database is upgraded automatically,** from schema 56 to 57.
  - **The upgrade permanently deletes chats left behind by agents you deleted before this version.** Chats with your current agents and with GleepGlorp are not affected. If you want to keep any of those old chats, copy what you need before upgrading.
  - Nothing needs to be reconfigured.
- In a narrow window, the browser tab's title still says "Settings — Appearance" while the Settings menu is showing.
