- **Apparatus deviation.** The spec prefers goldfinch, but goldfinch stopped delivering synthetic input on this host earlier in the session. The Executor used a dedicated headless Chromium 147 over CDP (`127.0.0.1:9335`) through Playwright:
  - a persistent raw-CDP context;
  - real input events, with `select_option` only on the native Provider and Model selects;
  - ignore-cache reloads via CDP `Page.reload {ignoreCache:true}`;
  - screenshots as the primary evidence.
- **Light variant theme.** The Light pass ran on the fresh context's Auto preference, which resolves to `data-theme=light`, rather than an explicitly set Light. This is recorded as a minor deviation; the rendering is identical. The Dark pass set Dark explicitly.
- **Dark pass batched.** For the variant repeat, the Executor ran D0 and D2–D10 as one batch with per-checkpoint evidence. The Validator judged each D checkpoint separately from one batched report.
- **Concurrency incident.** Three concurrent Executors shared one scratchpad, and their generic script names (`s1.py`…) collided.
  - Another run's Executor may have executed this run's step-6 script (an ignore-cache reload plus a rail click on this run's page) during this run's step-7 window.
  - This run's own first step-7 attempt executed another run's script, which timed out without touching this page.
  - Step 7 was redone with a uniquely named script. Its before-state matched step 6's end state, and a fresh re-read plus the server state confirmed the result.
  - The Validator judged the evidence sufficient.
  - Lesson: give each concurrent Executor its own scratch subdirectory.
- **Stale spec wording, fixed after this run.**
  - Step 9's "falls through to the first remaining agent, or the empty editor" is replaced with "returns to the Agents grid".
  - The Intent and locator notes still say "Studio".
