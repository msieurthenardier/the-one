# v0.11.2 — Time zone and housekeeping fixes

Patch release over [v0.11.1](https://github.com/msieurthenardier/the-one/releases/tag/v0.11.1). Follow-up fixes to the date and time work, plus smaller corrections.

## Fixed
- Opening the agent editor's Rules and notes tab repeatedly no longer leaves behind a clock listener each time.
- A time zone saved under an alias name (for example Oslo) now shows its check mark and is the active row in the zone search.
- If the browser cannot handle the chosen zone, the app now falls back to the server's UTC offset instead of the browser's local time.
- Numeric zone abbreviations such as `+14` or `-03` are no longer shown.
- The date line an agent sees no longer mentions `current_time` when the app could not confirm the tool is available.
- A malformed request body now gets a plain 422 error instead of a server error, on 24 routes.
- Hidden elements stay hidden everywhere in the app, through one shared rule.

## Notes
- **Upgrading:** there are no schema changes and nothing to reconfigure. The version number changes, so the app reloads its updated scripts and styles.
