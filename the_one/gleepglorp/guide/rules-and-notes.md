# Rules and notes

Rules are standing instructions you write for an agent, and notes are short facts the agent keeps for itself between chats.

## Where to find it

Open [Agents](#agents), pick a saved agent, then open its **Rules and notes** tab. The tab has a **Rules** section and a **Notes** section. Both save the moment you act, so there is no Save button to press and they don't count as unsaved changes on the agent. A new agent has to be saved first.

Changes apply to new and reopened chats, and to the next message in connector channels. The chat panel about the agent shows its rules and notes, read-only.

## Rules

A rule is one instruction in your own words, such as "Always answer in British English." Rules are added to the agent's instructions, numbered in the order you give them.

- Type the rule under "Add a rule" and choose **Add rule**. A counter shows how close you are to the limit of 500 characters per rule. All of an agent's rules together are limited to 4,000 characters.
- Each rule has a switch to turn it on or off without deleting it.
- Use **Edit** to change the wording, and **Move up** and **Move down** to change the order.
- Delete a rule with its delete button, and confirm.

## Notes

Notes are things the agent writes down so it can remember them in later chats, such as your preferences.

- Turn on **Let this agent keep notes** to allow it. When it is off, the agent can't see or write notes, but the notes it already has are kept.
- The agent can save, change and forget its own notes. You can **Edit** or delete any note, and **Clear all** removes every note after you confirm. A note you edited shows "Edited by you".
- Each note shows when it was saved and a link to the chat it came from.
- A note is limited to 400 characters. All notes together are limited to 4,000 characters. A usage line shows how much is used.

### The "check this" flag

A note can carry a warning flag. It means the note was written after the agent had read content that didn't come from you, such as a web page or a tool result. That content could have steered the agent. Read a flagged note before you trust it, and edit or delete it if it looks wrong. When you change a note's text, the flag is cleared, because you have reviewed it.

## Rules or notes?

Use a rule for something you always want. Use notes for things the agent picks up as it goes. Rules are yours to write. Notes are the agent's, and you can review them.
