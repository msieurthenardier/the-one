- **Apparatus deviation.** The spec names goldfinch, but goldfinch stopped delivering synthetic input on this host earlier in the session (see `workbench-navigation/runs/2026-10-01-21-03-48.md`). The Executor instead drove a dedicated headless Chromium 147 over CDP (`127.0.0.1:9334`) with Playwright:
  - A persistent raw-CDP browser context (`Target.createBrowserContext`, `disposeOnDetach:false`).
  - Real input events.
  - Screenshots as the primary rendered-state evidence.
- **Concurrency.** This run, `studio-agent-crud` and `system-provider-config` ran in parallel, each with its own Chromium and its own Executor/Validator pair.
- **Script-name collision.** The three Executors shared a scratchpad and used generic script names, which collided:
  - This run's first step-7 attempt executed another run's script, which targeted a different browser (port 9335).
  - The smoke page was unaffected.
  - Every Executor then switched to run-prefixed scripts, written and run in one command.
  - Lesson: give each concurrent Executor its own scratch subdirectory.
- **Spec fix applied after this run.**
  - Step 9 now states the fresh-document load explicitly.
  - The Preconditions now allow a CDP or Playwright apparatus.
- **Product observation (not a failure).** On the LLM Providers grid, a long provider name runs under the absolutely positioned type badge (`.entity-tile-badge`, at top 8px and right 8px).
