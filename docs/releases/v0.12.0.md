# v0.12.0 — GleepGlorp AI on macOS and Linux

GleepGlorp AI now installs the same way on all three desktops: download one file from this page, no Python and no command line. There is a new Mac app, a Linux AppImage and `.deb`, and a Windows installer that now closes the running app cleanly when you upgrade.

## Added
- **macOS app.** `GleepGlorp_AI-0.12.0-arm64.dmg` for Apple Silicon Macs on macOS 14 or later. Drag the app to Applications. It finds the tools you installed in your own shell (such as a Node from nvm). Closing the window keeps the app in the Dock, and clicking the Dock icon brings it back; Cmd-Q quits. Your window size and position are remembered. [Install guide](https://github.com/msieurthenardier/the-one/blob/main/docs/macos-install.md).
- **Linux packages.** `GleepGlorp_AI-0.12.0-x86_64.AppImage` (runs on any supported desktop, no terminal needed) and `gleepglorp-ai_0.12.0_amd64.deb` (installs through your package manager and upgrades through `apt`). Ubuntu 26.04 LTS and Debian 13 on GNOME are supported. [Install guide](https://github.com/msieurthenardier/the-one/blob/main/docs/linux-install.md).
- Every release now lists a `SHA256SUMS` file, so you can check a download.

## Changed
- **Upgrading on Windows no longer needs you to quit first.** The installer asks the running app to shut down cleanly, waits for it, and only then replaces the files; uninstalling while the app runs works the same way. [Windows guide](https://github.com/msieurthenardier/the-one/blob/main/docs/windows-install.md).

## Fixed
- On Windows, after you close the window to the tray, the app now correctly reports that its window is hidden.
- On macOS, the window no longer appears empty before the page has loaded.
- The model list that tells the app each model's context size now refreshes from the internet again. Before, one retired model blocked every refresh, so new models and changed limits never arrived. Models that are no longer listed upstream keep their last known size instead of disappearing.

## Notes
- **Windows, one-time forced close.** If you are upgrading from v0.11.8 while the app is running, the installer closes it by force once, because v0.11.8 does not yet know how to shut down on request. Nothing is lost; from this version on the close is clean.
- **macOS asks you to approve the app once.** The app is not notarized by Apple, so the first time you open it macOS says it cannot verify it. Approve it under System Settings › Privacy & Security › Open Anyway. The install guide shows each screen. Quit the app before replacing it with a newer version.
- Your chats, agents and settings stay where they were on every platform; nothing moves and there are no database changes.
