Soil Sensor server

Soil Sensor is a small local MCP server that reads moisture logs from a garden controller and lets an assistant say which beds need water. It works on files already on your computer.

Install

It is a Node program, started through its package runner. Use this command, with no further arguments:

npx -y @acme/soil-sensor

Register it with your assistant as a local program (stdio). The first start downloads the package, which takes a few seconds.

Notes

Logs are read, never changed. Most people start with one bed and widen it later. Corrections are welcome by post to the maintainers.
