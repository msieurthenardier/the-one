# v1.0.0 — GleepGlorp, the built-in assistant

The app now has its own assistant. GleepGlorp knows how the app works. It answers questions, fills in forms for you, and proposes changes. Nothing changes until you click Save or Approve.

## Added
- **GleepGlorp, a built-in assistant.** It ships with the app and is listed first in the agent picker, under "Built in". Ask it how something works, or ask it to set something up.
  - Choose its model in **Settings › Assistant › GleepGlorp**. Until a model is chosen, GleepGlorp shows how to set one up.
  - The same page has an on/off switch, a web access switch, a notes switch and chat retention (30 days by default). Nothing else about it can be changed: its prompt ships with the app and is shown read-only in **Settings › Prompts**.
  - It only helps with the app. It declines other requests, and it has no shell, file or code tools.
- **A help button on every page.** A violet button in the corner of Agents, Library and Settings opens GleepGlorp in a side drawer, beside the page you are on.
  - GleepGlorp knows which page and item are open, so "what does this do?" is answered about what you are looking at.
  - The drawer keeps its conversation as you move between pages, and **Open in Chats** continues it there.
  - Close it with the Close button or Esc. The button is hidden in Chats, where GleepGlorp is in the chat list.
- **GleepGlorp fills in forms; you save them.** Ask in the drawer, for example "here's the link to the MCP server I want, set it up". GleepGlorp opens the right editor and fills in its fields.
  - Filled fields are marked. They are unsaved edits, so the editor's checks, its unsaved-changes note and its leave warning all apply.
  - Nothing is stored until you click Save. A field you were already editing is left alone.
  - This works for agents, MCP servers, model providers, knowledge bases, Library secrets (name, description and allowed tools only), built-in tool settings, and Knowledge indexing.
- **GleepGlorp proposes changes; you approve them.** In a chat, ask for something bigger, such as "make me an agent that does X" or "add my GitHub MCP server to the ABC agent". GleepGlorp answers with a card that shows exactly what will change.
  - **Approve** applies only the fields shown, with the same checks as the editor. A request with several steps continues one approved step at a time. **Dismiss** changes nothing.
  - If the item changed after the proposal was made, Approve warns you first instead of overwriting it.
  - An editor already open on that item shows the new values, and your unsaved edits are kept.
  - GleepGlorp never proposes deleting anything.
- **Built-in help topics.** GleepGlorp looks things up in short help topics that ship with the app, covering agents, MCP servers, providers, knowledge bases, routines, rules and notes, secrets and settings.
- **Deleting a model provider that is in use** now shows which agents use it. A checkbox confirms that they will lose their model.

## Changed
- **The "Default agent" is gone.** Every chat names an agent, and GleepGlorp takes its place as the built-in agent.
- **"GleepGlorp" and "default" are reserved names.** If you already have an agent with either name, it is renamed once, for example to "GleepGlorp 2".
- **Notes have one design** for agents and for GleepGlorp. Notes can be deleted but no longer edited in place.

## Notes
- **The database is upgraded automatically,** from schema 52 to 56.
  - **The upgrade deletes the old Default agent and every chat that had no agent.** Chats with your own agents are not affected.
  - Nothing needs to be reconfigured.
- **GleepGlorp never handles secrets.** It never reads, stores, fills or proposes an API key, a sign-in or a secret's value. When a step needs one, it links to the page where you enter it.
  - If you paste a key into the chat, it may still repeat that key back in its reply. Keys belong on the page it links to, not in the chat.
- **Check what GleepGlorp fills.** A form filled or a proposal made after GleepGlorp read a web page or an MCP server's description is marked "Check this".
  - A link, command or address taken from outside content must be typed by you. GleepGlorp quotes it instead of filling it.
- **GleepGlorp works best with Claude-class models.** Small local models may struggle to use its tools, and the Settings page says so.
- **Connectors** (Discord, Telegram) can be read by GleepGlorp but not changed by it.
