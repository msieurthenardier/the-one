Repo Browser server

Repo Browser is a small local MCP server that lets an assistant list the files and recent commits of a repository on your computer. It only reads.

Install

It is a Node program, started through its package runner. Use this command, with no further arguments:

npx -y @acme/repo-browser

Register it with your assistant as a local program (stdio). The first start downloads the package, which takes a few seconds.

Notes

History is shown newest first. Most people point it at one repository first and widen it later. Corrections are welcome by post to the maintainers.
