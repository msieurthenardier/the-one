# v0.17.0 — Extended thinking follows the model

Extended thinking on a Claude provider now applies only to the models that support it, and new Claude providers start with it on.

## Changed
- **Extended thinking is on by default for a new Claude provider.** This covers all three Claude provider types (API key, Claude Plan (OAuth) and Claude Plan (Token)). Providers you already saved keep their setting.
- **Thinking is only used by models that support it.** Claude models from version 4.6 on reason step by step before answering. Older models on the same provider, such as Haiku 4.5, answer without it.
- **The switch's help text says so.** It now reads that older models on the provider answer without thinking.

## Fixed
- **One provider can serve thinking and non-thinking models.** With Extended thinking on, an agent on a model that does not support it used to fail every turn with "adaptive thinking is not supported on this model". It now answers normally.
- **A model the app misjudges recovers by itself.** If Claude still reports that a model does not support thinking, the app retries once without it and stops asking that model for thinking until the app restarts.

## Notes
- No database upgrade, and nothing needs to be reconfigured.
- To use thinking on a provider you saved earlier, open it in Library › Model providers and turn Extended thinking on.
- Thinking uses more of your plan or API quota and makes replies slower. Turn the switch off on a provider to stop it for every model.
- The `THE_ONE_ANTHROPIC_EXTENDED_THINKING` environment setting now only affects providers with no saved choice, which means providers created before this version that never saved the switch.
