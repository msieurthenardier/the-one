# v0.16.3 — One work line per turn

A chat turn now shows one collapsible work line and one reply, instead of a bubble and a tool group for every step the agent takes.

## Changed
- **One work line per turn.** While an agent works you see a single "Working" line with a count of tool calls, the tool that is running and a quiet preview of what it is writing. When it finishes, the reply appears as one message. Click the line to see every step: the agent's notes to itself, its thinking and each tool call with its result.
- **Turns that end early say why.** A turn you stop, one that hits an error and one that runs out of steps each keep everything the agent wrote inside the work line, which reads "Stopped", "Ended with an error" or "Paused at the step limit".
- **Charts and widgets appear with the reply.** They are drawn when the reply lands, not while it is being written.
- **New agents start with 50 steps.** The step limit for an agent you create in the app now starts at 50 instead of 20. Existing agents keep their setting.

## Fixed
- **Turning a tool back on warns you first.** Switching a built-in tool on from its Settings tile now tells you if that would narrow any agent's own tool settings, and lets you cancel.
- **Clearer error when an MCP server can't start.** If a local MCP server fails to start because a folder it is allowed to write to does not exist, the error names that folder. It used to say only "Connection closed".
- **Pending prompt changes stay on screen.** If the app can't refresh an agent's waiting prompt changes when you come back to the window, it keeps the list and says it could not refresh.

## Notes
- No database upgrade, and nothing needs to be reconfigured.
- After you reopen a chat, a turn that was stopped or hit an error looks like a finished one.
