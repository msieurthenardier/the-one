## Executive Summary

**The suite is green and the code is in reasonable shape, but the test gate has become the bottleneck.** Measured today:
- Unit: 5598 passed, 0 failed, **697 s**, past the 600 s line the operator set after M22.
- Browser: 1831 items, 0 failed, **41.5 min**.
- Full sequential gate: about 53 min, paid on every leg.

**The causes are measured, not guessed.**
- About **75% of unit time is fixture setup**. Every test database replays all 46 migrations from v0, with an fsync per commit. That cost grows with every migration, which explains why per-test cost doubled since Mission 7.
- About **52% of browser time is starting and stopping 936 per-test uvicorn servers**. Each of those servers replays the same migrations again.

**Deleting tests is not the lever.** Every redundancy candidate together is worth about 1.5 min.

**The fixes, and what they buy.**
- A per-session template database, lane parallelism (3 lanes measured comfortable on this host) and a lane rebalance are all low to medium risk.
- Projected unit lane: about 4 min.
- Projected local browser gate: about 13–15 min.
- Projected CI long pole: about 12–15 min.

**CI is serial and unlocked.**
- The browser suite runs as one serial task.
- Tasks install unlocked dependencies from scratch on every build.
- There are no path filters, so every flight-log push pays the full ~40 min plus an installer build, on the operator's own machine.

**Security.** Every surface new since 08-27 was traced and holds:
- the credential gate, including the new window routes;
- FTS5 escaping;
- folder-walk containment and the symlink policy;
- the dual-gated seams;
- the Ollama name→URL path;
- connector token handling.

The roundtable downgraded the one medium security finding to hardening once it was reproduced. The only real exposure found is outside the repo: the local CI stack publishes MinIO, Vault, Concourse and TSA on all interfaces, with MinIO's default credentials guarding the installer bucket.

**The squawk backlog is not rotting.** The oldest item is 24 days old. One squawk is fixed but unrecorded, five have drifted citations and two are too big to be squawks.
