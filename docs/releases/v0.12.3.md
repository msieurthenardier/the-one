# v0.12.3 — A rebuilt chat

The chat has been rebuilt. You can now copy a whole reply, queue several messages, keep a draft in each chat, see which chats are busy, and continue an agent that stopped at its step limit.

## Added
- Each finished agent reply has a Copy button next to its time. It copies the reply as the agent wrote it, with its Markdown.
- When an agent stops because it used all its steps for a message, the chat now says so instead of ending silently. It shows a Continue button and a link to the agent's "Max iterations" setting. Connector chats get a short line saying the agent stopped, and the command line prints the same notice.
- You can send several messages while an agent is still answering. Each waits as its own "Queued" chip, up to 10, and each can be cancelled. They are sent in order, one per finished reply.
- The Chats list shows a small spinning ring on a chat while its agent is working, and a dot when a reply arrives in a chat you are not looking at.
- Each chat keeps its own unsent message and attached images. Switching to another chat and back brings them back.
- Replies now render ~~strikethrough~~, task lists with checkboxes, and plain web addresses as links.

## Changed
- When an agent fails, the chat shows a short headline, with the full error under "Technical details".
- After you press Stop, the chat shows "Stopped.". If a queued message was dropped, it says so.
- An agent's thinking now always appears above the reply it belongs to, and tool activity shows a count.
- Headings in replies are sized to fit the app. Wide tables scroll sideways inside the reply.
- The Copy button on a code block shows a check mark when it has copied.
- Only one notification shows at a time, and the newest replaces the last. "MCP server created" and "Connector created" now stay on screen.
- The agent and model provider editors use sentence-case labels.
- In the Chats list, a connector chat shows its platform's name, for example "Discord".
- In the model lists, model names are shown in a fixed-width font.

## Fixed
- A link in a reply can no longer point to another website by using backslashes or hidden control characters.
- Errors from an OpenAI-compatible provider no longer say "Ollama".
- After you pick an agent for a new chat, the cursor is in the message box.
- In a chat whose agent was deleted, Attach is now disabled too.
- A "Loading model…" line no longer keeps spinning after the reply ends with an error or Stop.
- Deleting a chat while the app is offline now tells you why it failed.
- If starting an MCP sign-in from a chat fails, the stale sign-in link is removed and the button comes back.
- In Jump to and the agent picker, the highlighted row no longer jumps to another row when the results refresh.
- In the MCP server and connector editors:
  - a header or variable row's remove button is now named after the key as you typed it;
  - after a save, the rename hint clears.

## Notes
- No database changes. Nothing needs to be reconfigured.
- For API users: the `/api/chat` result now includes `"step_limit": true` when the agent stopped at its step limit.
