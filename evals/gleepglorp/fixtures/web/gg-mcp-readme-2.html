Bank Feed server

Bank Feed is a small local MCP server that reads statement files from a folder and lets an assistant total them by month. Nothing leaves your computer.

Install

It is a Node program, started through its package runner. Use this command, with no further arguments:

npx -y @acme/bank-feed

Register it with your assistant as a local program (stdio). The first start downloads the package, which takes a few seconds.

Notes

Statements are read, never changed. Most people point it at a single folder first and widen it later. Corrections are welcome by post to the maintainers.
