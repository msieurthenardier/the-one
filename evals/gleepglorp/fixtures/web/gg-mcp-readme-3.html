Pantry Scan server

Pantry Scan is a small local MCP server that keeps a list of what is in your kitchen and lets an assistant suggest dinners from it. The list is a plain file on your computer.

Install

It is a Node program, started through its package runner. Use this command, with no further arguments:

npx -y @acme/pantry-scan

Register it with your assistant as a local program (stdio). The first start downloads the package, which takes a few seconds.

Notes

Quantities are optional. Most people start with the freezer and widen it later. Corrections are welcome by post to the maintainers.
