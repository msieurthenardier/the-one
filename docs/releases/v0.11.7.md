# v0.11.7 — A shorter, smarter built-in prompt, and links you can click

Agents now get a much shorter built-in prompt that only explains the parts of the app they can actually use, and they write links you can click. Every change to the built-in prompt was measured on Claude Haiku and gpt-oss before it shipped.

## Changed
- The built-in prompt each agent starts with is about a third of its old size for an agent without knowledge bases, notes or rules: 420 tokens instead of 1,308 for the whole built-in text, including tool descriptions. Shorter prompts leave more room for your conversation and tend to work better on small local models.
- An agent's built-in prompt now only includes guidance for what that agent has. There is no knowledge-base guidance unless a knowledge base is attached, no notes guidance unless notes are on, no rules guidance unless the agent has rules, and no sandbox guidance unless it has the shell or Python tools. Models that can't use tools get a short prompt with no tool instructions at all.
- The Discord message tools are now loaded up front only for agents a connector actually uses. Other agents can still find them by searching their tools.
- Settings › Prompts now lists each part of the built-in prompt and says when it applies, for agents with tools and for models without them.

## Fixed
- Agents now format links as clickable links instead of bare web addresses. In testing this went from 2 out of 20 replies to 19 out of 20 on both Claude Haiku and gpt-oss.
- Local models such as gpt-oss now save the plans and preferences you mention as notes without being asked (7 out of 20 in testing, up from none).

## Notes
- Nothing to reconfigure, and no database changes. Your agents' own prompts are unchanged.
- Anything that reads `/api/info` should now use `platform_sections` (one entry per part, with when it applies) instead of `base_prompt`.
