Weather Desk server

Weather Desk is a small local MCP server that gives an assistant forecasts, rain alerts and tide tables for a town. It runs on your own computer and needs no account.

Install

It is a Node program, started through its package runner. Use this command, with no further arguments:

npx -y @acme/weather-desk

Register it with your assistant as a local program (stdio). The first start downloads the package, which takes a few seconds.

Notes

Forecasts refresh every thirty minutes. Most people attach the server to a single assistant first and widen it later. Corrections are welcome by post to the maintainers.
