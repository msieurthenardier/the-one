**Why this run supersedes the 02-39-45 run.** The earlier run (6/8) surfaced a
suspected `next_session` defect. Follow-on server-side instrumentation proved the
propagation mechanism correct (`_restore_session` rebuilds the live agent from
the stored row on rejoin) and identified the failures as a spec-observability
confound: a sentinel in the agent's replies is only reliably obeyed on the first
turn of a fresh conversation, because inside an established conversation the model
anchors on its own prior replies and on the revision tool call's arguments (which
carry the new prompt text into context). The instrumentation was reverted; the
spec was corrected to measure the fresh-conversation observable; this run is the
authoritative pass.
