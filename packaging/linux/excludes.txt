# Libraries the frozen bundle must NOT carry: the host desktop provides them, and a
# second copy next to the host's WebKit would put two GLibs in one process
# (flight DD2 gate 3). One fnmatch pattern per line, matched against the file's base
# name inside the bundle. Patterns are anchored on the family's real soname, so
# wheel-vendored copies with hashed names (pillow.libs/libharfbuzz-<hash>.so, which
# Pillow needs and links by its hashed name) do NOT match.
# Reference: the AppImage project's excludelist, matched by family.
