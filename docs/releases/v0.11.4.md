# v0.11.4 — Claude Plan (Token) provider

Patch release over [v0.11.3](https://github.com/msieurthenardier/the-one/releases/tag/v0.11.3). A second way to use a Claude subscription: paste a token instead of signing in.

## Added
- **Claude Plan (Token) provider.** Add a model provider of this type and paste a token from `claude setup-token`; agents then chat on your Claude subscription with no sign-in flow. The editor shows an "expires around" line for the token, with a warning within 30 days and "may have expired" after.

## Changed
- The existing OAuth sign-in provider is now labelled "Claude Plan (OAuth)". It is otherwise unchanged.
- When a Claude plan refuses a model with a bare "Error" (HTTP 429), the app now explains it. The token type also explains a rejected token.

## Notes
- Plan tokens work with `claude-haiku-4-5` here; the plan refuses other models on the account side, as it does for the OAuth type.
- **Upgrading:** the database is upgraded automatically on first start (one schema step). Nothing to reconfigure.
