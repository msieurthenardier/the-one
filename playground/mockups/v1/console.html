Three observations before we write v10:

SQLite has no ALTER TABLE DROP CONSTRAINT, so the CHECK swap forces the whole-table rebuild ceremony — CREATE new + INSERT-SELECT old + DROP old + RENAME new under PRAGMA foreign_keys=OFF/ON brackets. The v8/v9 pattern of individual await conn.execute(...) calls (not executescript) carries through so partial-apply retries are safe.

The 'sse' → 'streamable-http' rename must happen inside the INSERT INTO mcp_sources_new SELECT ... step (CASE WHEN type='sse' THEN 'streamable-http' ELSE type END) rather than as a pre-rebuild UPDATE — the old CHECK is still active and would reject the new literal.
