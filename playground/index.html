UI / UX Direction Review

Three calibrated directions.

Three exploratory mockups for the next chapter of GleepGlorp AI — covering Chat, Studio, and Administration. Each leans into a different design hypothesis, but all three are calibrated to look like a real, professional product: restrained palettes, generous spacing, single accent used sparingly.

v2 recalibration. The original mockups read as too flashy and too dense. These have been re-spec'd against Linear, Vercel, Notion, GitHub, Stripe, Figma's own UI, and Raycast — restraint over stunts. v1 is archived at atelier · console · holograph for comparison.
Direction A · 1,404 lines

Atelier

A calm, beautifully-typeset surface where the conversation is the work.
Dominant
Calm focus
Palette
Warm near-white · ink · sage accent
Type
Inter · JetBrains Mono
Layout
Sidebar + content, tabbed nav
Theme
Light
Refs
Linear · Notion · Stripe Dashboard
Identity
  1. Typographic hierarchy. Weight and size do the work; color rarely communicates importance.
  2. Warm neutral palette. Tinted whites and inks so the surface feels considered, not clinical.
  3. Quiet attribution. No bubbles. Just a one-line name + time above each message; tool calls collapse into hairline blocks that don't compete with the prose.

Direction B · 1,968 lines

Console

A keyboard-fluent, information-rich workspace for hours of focused work.
Dominant
Power-user fluency
Palette
Calm dark · bone · single cyan accent
Type
Inter · JetBrains Mono (used sparingly)
Layout
Three-pane workspace · ⌘K palette
Theme
Dark
Refs
Linear · GitHub · Vercel · Raycast
Identity
  1. Three-pane shape. Sessions/agents · conversation · inspector. The power-user surface survives — calmer.
  2. Inline tool calls. Collapsible blocks showing tool, args, duration; mono confined to inside the block.
  3. Command palette as the keyboard surface. ⌘K opens a clean modal — grouped commands, real shortcuts shown there and in one status segment, not on every button.

Direction C · 1,874 lines

Holograph

A workspace where the primary objects are cards on a surface you can arrange.
Dominant
Spatial composition
Palette
Warm white · ink · one blue accent
Type
Inter · JetBrains Mono
Layout
Card grids · top nav
Theme
Light
Refs
Figma · macOS Notes · Pitch · Linear triage
Identity
  1. Card-as-object metaphor. Sessions, agents, providers, tools — all rendered as discrete bordered cards in calm grids.
  2. Quiet depth. A single soft shadow grows by one step on hover. No scale, no glow, no agent-color bleed.
  3. One restrained accent. Used only on primary buttons, focus rings, the active-nav underline, and a thin indicator on the currently-active card.

How to read these

Open all three. Sit with each for a few minutes — try to imagine living in it for an hour-long session. The three are philosophically distinct (calm / fluent / spatial), not just visually distinct.

When you've picked a direction — or a blend (e.g. "Atelier's calm with Console's inspector") — tell me, and I'll run it through a proper brainstorm → spec → implementation-plan cycle for the real app.
