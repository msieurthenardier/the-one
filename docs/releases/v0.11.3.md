# v0.11.3 — Model providers move to Library

Patch release over [v0.11.2](https://github.com/msieurthenardier/the-one/releases/tag/v0.11.2). Model providers now live in Library, next to knowledge bases, MCP servers and connectors.

## Changed
- **Model providers are in Library.** They are the first group in the Library list, with their own entry in the Add menu, a card on the Library start page, and a place in Jump to (Ctrl K).
- **Library has a front door.** `#library` is now its own page, and the older section addresses such as `#library/mcp` lead to it.
- **Settings no longer has a Models section.** Old `#settings/providers` links no longer work; use Library.

## Fixed
- In the provider editor, a slow response from an earlier save or delete can no longer move you back to a provider you had left or discard an editor you had moved to.

## Notes
- **Upgrading:** there are no schema changes and nothing to reconfigure. Your providers are unchanged; only where you find them moved.
