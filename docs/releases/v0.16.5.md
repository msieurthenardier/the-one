# v0.16.5 — MCP arguments, one per row

A local MCP server's arguments are now entered one per row and saved exactly as you typed them.

## Changed
- **Arguments are entered one per row.** In Library › MCP servers, the Arguments field of a local-command server is now a list of rows with "+ Add row", like Environment variables. It replaces the chip field.
- **You set the order.** Each row has Move up and Move down buttons beside Remove, so an argument can be moved without retyping it.
- **Spaces at the ends are trimmed.** On Save, spaces before and after an argument are removed and empty rows are dropped. Spaces inside an argument, such as a folder name with a space, are kept.

## Fixed
- **A repeated argument is kept.** Entering the same value twice, as in `--flag a --flag a`, used to save only one of them.
- **A comma no longer splits an argument.** A value such as `--allow=a,b` used to become two arguments. It is now saved as one.
- **Forget tools list and Reset connection start fresh each time.** After you confirmed either one, the button could come back still asking "Forget tools list?", and a single click would run it again. It now returns as a normal button that asks before it acts.
- **The two "+ Add row" buttons can be told apart.** In the MCP server editor, a screen reader or voice control now hears "Add row to Arguments" and "Add row to Environment variables" (or "Add row to Headers"). The buttons look the same as before.

## Notes
- No database upgrade, and nothing needs to be reconfigured. The arguments of your existing servers are unchanged.
- If an argument was stored with a space at its start or end, the space is removed the next time you save that server.
